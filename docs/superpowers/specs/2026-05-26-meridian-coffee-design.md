# МЕРИДИАН — дизайн-документ

**Дата:** 2026-05-26
**Статус:** черновик, ожидает ревью
**Автор:** Гульназ (PM) + Claude

---

## 1. Контекст и зачем строим

В РФ сложился развитый рынок спешелти-кофе, но никто из заметных игроков не закрывает полный путь клиента «впервые слышу о спешелти → нашёл своё зерно → получаю его регулярно домой» в едином опыте. Tasty Coffee лидер в подписке, но без онбординга-квиза. Double B и Кооператив Чёрный сильны в бренде, но слабы в e-commerce. Прямой международный аналог нашей идеи — Trade Coffee (drinktrade.com).

МЕРИДИАН занимает этот зазор: **спешелти-кофейня с подпиской, которая ведёт клиента от первого знакомства до постоянного покупателя через образовательный контент**.

Помимо коммерческой задачи, проект служит вторичной цели — портфолио PM-роли: расписать продуктовую воронку с измеримыми метриками, recurring revenue моделью и понятной историей улучшения метрик.

## 2. Целевая аудитория

- **Первичная:** 25–40 лет, IT/дизайн/креативные профессии, доход выше среднего, ценят качество и историю продукта
- **Вторичная:** «начинающие» спешелти-аудитория — те, кто пьёт в Старбаксе, но любопытны
- **Средний чек в кофейне:** 350–700 ₽
- **Подписка:** 1 500–3 500 ₽ / месяц (зависит от тарифа)

## 3. Позиционирование

**Сообщение в одну строку:** «Кофе с координатами — каждое зерно знает откуда оно».

**Tone of voice:** образовательный, премиальный, с географической метафорой. Тексты ведут себя как редактор National Geographic, а не как маркетолог супермаркета. Никаких «вкусно и недорого».

**Чего избегаем:**
- Хипстерских клише («крафтовый», «авторский» — это пустые слова)
- Снобизма («только настоящие ценители»)
- Технического жаргона без объяснения (washed, natural, V60 — объясняем при первом упоминании)

## 4. Главная фишка (USP) — воронка из трёх ступеней

Это центральное продуктовое решение. Каждая ступень — отдельная страница и отдельная PM-метрика.

### Ступень 1 — Вкус-помощник (C)
**Цель:** превратить новичка из «боюсь заказать не то» в «знаю что хочу».

**Механика:** квиз из 3–4 вопросов:
1. Любите кислое, сладкое или горькое?
2. С молоком или без?
3. Это для дома или для кофейни?
4. (опционально) Первый раз пробуете спешелти?

→ Алгоритм выдаёт 1–2 рекомендации зерна с объяснением «почему именно это подходит вам».

**PM-метрика:** конверсия «прошёл квиз → открыл карточку зерна → нажал заказать/в подписку».

### Ступень 2 — Карточка зерна (B)
**Цель:** влюбить клиента в конкретное зерно через историю.

**Содержимое страницы:**
- Название, страна, регион, ферма
- Координаты (визуально как метаданные — это и есть «меридиан»)
- Высота произрастания, обработка, разновидность арабики
- Вкусовой профиль (3–5 нот) с расшифровкой
- Краткая история фермы/фермера
- Профиль обжарки (light / medium / dark + дата обжарки)
- Цена за 250 г и 1 кг
- CTA: «Заказать» (разовая покупка) + «В подписку» (рекуррентная)

**PM-метрика:** среднее время на странице, конверсия в добавление в корзину/подписку.

### Ступень 3 — Подписка (A)
**Цель:** удержать клиента, превратить разовую покупку в LTV.

**Тарифы (предложение, уточним при дизайне):**
- **Знакомство** — 250 г каждые 4 недели, разнообразие зёрен по нашему выбору
- **Постоянство** — 250 г каждые 2 недели, фиксированное зерно (вы выбираете)
- **Открыватель** — 500 г каждые 2 недели, ротация по вкусовому профилю

**Механика оформления (MVP):**
1. Клиент выбирает тариф
2. Заполняет форму (имя, телефон, адрес, способ доставки, пометки)
3. Данные сохраняются в Supabase
4. Клиент получает письмо «мы получили заявку, свяжемся в течение N часов»
5. Админ (в MVP — мы вручную) получает уведомление, связывается, отправляет ссылку на оплату, организует доставку

**PM-метрика:** LTV (расчётный), churn (расчётный по отказам), MRR (расчётный).

## 5. MVP-скоуп

### Входит в v1 (Balanced MVP, ≈ 1–2 недели работы)

- [ ] Главная (`/`) — hero с одним сообщением + 3 CTA-входа в воронку
- [ ] Квиз (`/quiz`) — алгоритм клиентский, без БД, рекомендация на основе if/else по тегам зёрен
- [ ] Каталог зёрен (`/beans`) — список с фильтрами по стране, обработке, вкусовому профилю
- [ ] Карточка зерна (`/beans/[slug]`) — полная информация по структуре выше
- [ ] Подписка (`/subscription`) — 3 тарифа + форма заявки
- [ ] О нас (`/about`) — короткая страница: история, адрес, контакты, соцсети
- [ ] Supabase для зёрен (`beans` table) и заявок на подписку (`subscription_requests` table)
- [ ] Письма: подтверждение заявки клиенту + уведомление админу (через Resend или SMTP)
- [ ] Адаптивная вёрстка (мобильная как приоритет)
- [ ] Метатеги и OG для соцсетей
- [ ] Деплой на Vercel

### Не входит в v1 (отложено на v2/v3)

- ЛК пользователя (регистрация, история заказов, управление подпиской)
- Онлайн-оплата (ЮKassa) — в MVP оплата по ссылке после заявки
- Админ-панель для управления зёрнами (в MVP редактируем через Supabase напрямую)
- Блог / образовательный контент о методах заваривания
- Отзывы и рейтинги зёрен
- Меню кофейни и онлайн-заказ напитков
- Профили бариста и расписание смен
- Программа лояльности и накопительные баллы
- Мобильное приложение
- Английская локализация

## 6. Бренд-система

### Палитра — Сумеречная экспедиция

| Роль | Hex | Применение |
|------|-----|------------|
| Background — тёмная хвоя | `#0D1F1C` | Основной фон, тёмные секции, карточки зёрен |
| Accent — медь | `#D4A06B` | CTA-кнопки, заголовки, акценты, метки |
| Light — пергамент | `#F0E0C8` | Светлые секции, текст на тёмном, поверхности |
| Muted text | `#D4A06B` at 60–70% opacity | Метаданные, второстепенный текст |

### Типографика

- **Заголовки:** Georgia (засечки, системный, бесплатный) — даёт «редакторский» премиум
- **Метаданные / координаты:** Courier New (моноширинный) — лабораторный нюанс, технические элементы
- **Основной текст и UI:** Inter (Google Fonts) — современный, читаемый стандарт

### Логотип

Вордмарк: «МЕРИДИАН» прописными буквами Georgia с разрядкой `letter-spacing: 8px`. Под вордмарком — техническая строка моноширинно: «SPECIALTY COFFEE · EST. 2026».

В v1 без отдельного графического знака — только вордмарк. Знак можно добавить в v2.

### Голос

- Обращение на «вы»
- Конкретика вместо общих слов («ягоды и тёмный шоколад» вместо «насыщенный вкус»)
- Цифры и факты («1 900 м над уровнем моря» вместо «высокогорный»)
- Без эмодзи в основных текстах (можно в письмах/соцсетях)

## 7. Карта сайта и навигация

```
/                — Главная
/quiz            — Вкус-помощник
/beans           — Каталог зёрен
/beans/[slug]    — Карточка зерна
/subscription    — Подписка (тарифы + форма)
/about           — О нас, контакты
```

**Главная навигация (header):** Зёрна · Подписка · О нас. Квиз НЕ в шапке — он живёт как CTA на главной и в каталоге, чтобы не отвлекать опытных пользователей.

**Footer:** контакты, адрес, соцсети, копирайт.

## 9. Тех-стек

- **Framework:** Next.js (App Router, последняя версия) — тот же стек, что АвтоДом
- **UI:** Tailwind CSS + shadcn/ui — переиспользуем подход и компоненты
- **БД:** Supabase (Postgres + Auth-ready на v2)
- **Письма:** Resend — простая интеграция, бесплатный тариф на 3 000 писем/месяц достаточен для MVP
- **Деплой:** Vercel
- **Контроль версий:** git (нужно инициализировать репозиторий)

Документация Next.js берётся из `node_modules/next/dist/docs/` (как в АвтоДоме — в проекте может быть актуальная версия с breaking changes).

## 10. PM-метрики (что будем измерять с первого дня)

**Воронка:**
1. Посетители главной
2. → Прошли квиз (% от посетителей)
3. → Открыли карточку зерна (% от прошедших квиз)
4. → Перешли на страницу подписки (% от открывших карточку)
5. → Отправили заявку на подписку (% от перешедших)

**Дополнительно:**
- Среднее время на карточке зерна
- Конверсия каталога → карточка
- Расчётный LTV первых N клиентов
- Источники трафика (UTM)

В v1 — отслеживание через Vercel Analytics (встроенное, бесплатное на старте) + Google Analytics или Plausible.

## 11. Риски и митигации

| Риск | Митигация |
|------|-----------|
| Никто не оставит заявку на подписку | В первые 2 недели после запуска — личный прозвон знакомых из ЦА, сбор обратной связи. Это нормальный путь для MVP. |
| Контент по зёрнам долго писать | Для запуска достаточно 6–8 зёрен. Использовать описания с упаковки + дополнить координатами и историей. |
| Соблазн добавить ЛК / оплату в v1 | Жёстко держать скоуп. Если возникает желание — фиксировать в раздел v2 этого документа, а не сразу строить. |
| Сайт визуально окажется обычным | Каждый компонент проходит проверку «выглядит как МЕРИДИАН?» — Georgia + медь + координаты. Если без этих признаков — переделать. |
